# JSON Visualizer

This is a simple web-based tool to visualize JSON data in a collapsible tree structure.

## How to Use

1.  Open the `index.html` file in your web browser.
2.  Paste your JSON data into the text area.
3.  Click the "Visualize" button.
4.  The JSON data will be rendered as a tree below the button.

## Features

*   Syntax highlighting for different JSON data types.
*   Collapsible nodes for easy navigation of large JSON objects.
*   The first level of the JSON tree is expanded by default.
*   Error handling for invalid JSON.
